Instructions to install Sass
Learn Bootstrap and Sass by Building a Portfolio Website

-Install Node with NPM

command line: npm install -g npm

Or download it here: ( https://nodejs.org/en/download/ )

Click on package downloaded and it will install authomatically

Check NPM version

npm -v

Check Node version

node -v

-Install package.json on your Project

On your terminal change direcory, and add command:

npm init, enter

Follow prompts on terminal. It will install package.json in your project folder

Install packages

Go here https://npmjs.com to search for packages to install

  • Dart-sass

    search: dart-sass. From menu choose: dart-sass a pure javascript implemention of sass, click on it. On page showed loof for install and copy command: npm i dart-sass --save-dev sass terminal will show: "npm install --save-dev sass" click enter.

    This will create a new folder in your project called: node_modules where all the packages will be installed

  • Bootstrap

    scroll down to INSTALLATION and copy the command line code npm install bootstrap --save

    On command line paste the above code and add "--save", since --save does not appear on the bootstrap page

  • fontawesome

    go to https://fontawesome.com

    Click start for free

    Scroll down and click on NPM look for the code and copy to install npm install --save @fontawesome/fontawesome-free press enter

  • autoprefixer

    Go https://npmjs.com search for autoprefixer clidk on the first result

    Search term "install" and copy npm install postcss-cli autoprefixer --saveflag it with "--save "

Edit package.jason

Open the package.jason file and scroll down to "scripts":{ } in the parenthesis add the following: "compile:sass": "sass --watch scss:assets/css" which is: the name of the package: "sass", space, (a comand --watch (so sass keeps compiling css)space scss,and the source of your sass files in your project directory exemple: assets/css"

Inside your project folder create a new folder named: "scss", inside your scss folder create a new file custom.scss (example)

On Terminal

type: npm run compile:sass (or however you called your script in the jason package) the command typed will create a new folder "assets" and a subfolder named: css (assets/css) also will create a custom.scss.map file

The command will also generate a new compiled focus-style.css style sheet from your focus-style.scss
