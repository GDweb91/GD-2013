5. Phase 2 — Entity graph + GEO retrofit DONE

scripts/fix_schema.py (new — idempotent, additive-only, marker-guarded)

Ran across all 45 active interior pages. It never rewrites existing JSON-LD; it does two things:

  1. Injects a consistent entity @graph before </head> on every page:
    • Organization/ProfessionalService — @id: https://gdprowebdesigns.com/#organization — the canonical business entity (real Everett NAP, geo, hours, areaServed = MA + 6 counties + 19 cities, sameAs FB/LinkedIn/YouTube, both Google certs, founder → #person).
    • Person — @id: …/#person — JA Armira: jobTitle, worksFor → #organization, hasCredential, sameAs, and a knowsAbout list (web design, WordPress, WooCommerce, SEO, local SEO, Google Ads, GEO, …) — the E-E-A-T signal AI engines use for attribution.
    • WebPage — @id: <url>#webpage — per-page URL + title, isPartOf/about/publisher → #organization, plus speakable → .quick-answer on pages that have an answer block.
  2. Normalised 24 fake per-city PostalAddress blocks in existing schema — pages that claimed the business was located in Jamaica Plain / Winchester / Malden / Chelsea / Boston / etc. now all state the real Everett address. Every live page's NAP is now identical.

Residual: ~24 pages still carry slightly-off geo coordinates in their old blocks — lower-risk than a wrong city name; flagged by the script for a later cleanup.

6. Phase 3 — WordPress town pages IN PROGRESS

What was discovered

  • Town pages are a custom post type: service_city (label "Cities"), 41 published, URL pattern /gd-blog/service-area/<slug>/, taxonomy service_state (Massachusetts = term id 4). They are already well-differentiated.
  • The %%post_title%% bug — page titles come from a custom mu-plugin, wp-content/mu-plugins/gd-seo-core.php, not AIOSEO settings. The local copy already had the correct code (%s + sprintf); the live copy was a stale version serving the literal string Web Designer in %%post_title%%, MA. Affected ~30+ pages including rowley-ma (ranks ~pos 7).
  • Per-city intro text ("Davis Square, Union Square…") comes from a curated PHP array gd_blog_city_intros() in functions.php, with an optional per-post ACF field city_intro as an override. ACF fields were not exposed to REST.
  • The local WordPress install (~/Local Sites/gd-blog/) has a stack of undeployed local changes and has diverged from live in both directions with no deploy pipeline.
